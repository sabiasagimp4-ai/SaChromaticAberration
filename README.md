# 色収差 (SaChromaticAberration)

YMM4 用の映像エフェクトプラグインです。Crate's Chromatic Aberration の見た目を参考に、
波長ごとに参照位置をずらした複数サンプルを合成し、プリズム状の色収差を作ります。

## パラメーター

| 名前 | 内容 |
| --- | --- |
| 収差 | 中心から外側へ色をずらす量 (px)。画面端の中点での値で、中心では 0、四隅ではさらに大きくなります。効果の主役。 |
| 減衰 | 選択した形式の強さ。冪乗形式では指数です。0 なら全面同じ量、3以上なら逆二乗より急に周辺へ集中します。 |
| 半径 | 減衰が広がる範囲 (%)。100%が従来の画面基準です。50%なら半分の距離で同じ強さになり、200%なら広い範囲に分散します。 |
| 減衰形式 | 冪乗（設定値）、三乗、四乗、六乗、指数から選択できます。三乗以上と指数は逆二乗より急な変化です。 |
| ラジアル | 中心まわりにねじりながらずらす角度 (°)。渦巻き状の収差。 |
| スケール | 色ごとに拡大率を変えてずらす量 (%)。奥行きのあるズレ。 |
| 中心X / 中心Y | ずれの中心位置 (px)。0px で画像中央。YMM4 の拡大縮小より前の、素材のピクセル空間で数えます。 |
| ステップ数 | 分光サンプル数の上限 (2〜2048)。少ないと段階的、多いと滑らかですが重くなります。 |
| 強さ | 元の映像との合成量 (%)。 |

正規化半径は縦横それぞれの半分の長さで割って求めるので、収差の等高線は画像と同じ縦横比の楕円になります。
画面端の中点が 1.0、四隅が約 1.41 で、減衰 2 のときの四隅の収差量は設定値の約 2 倍です。

既定値は収差 40px / 減衰 2.0 / 半径 100% / 減衰形式「冪乗」 / ラジアル 8° / ステップ数 32 です。
必要サンプル数がステップ数の上限を超えると縞が出ることがあります。
滑らかにする場合はステップ数を増やしますが、描画負荷も増えます。
参考画像のような柔らかい弧を出すには、素材自体がボケている必要があります。
細部が残っている素材に同じ設定を当てると、虹色は同じでも細かい模様がそのまま残り、より賑やかな絵になります。

収差・ラジアル・スケールがすべて 0 のときは、出力が入力と完全に一致します
(分光の重みをチャンネルごとに正規化しているため)。

半径を小さくすると、中心付近から収差が急に立ち上がります。半径を大きくすると、画面全体へゆっくり広がります。
減衰形式を「三乗」「四乗」「六乗」にすると、同じ半径でも外側へより急に収差が強くなります。「指数」は半径1を境にさらに急峻に増えます。

サンプル数はずれ量から必要数を計算して自動で間引きます。ステップ数は上限としてだけ働くので、
大きい値を入れても、ずれが小さいフレームでは描画コストは増えません
(ずれが 0 のフレームは 2 サンプルまで落ちます)。

## 指数スケールと半径の適用先

- 「スケール方式」→「指数（反転なし）」で、倍率を `exp(clamp(スケール/100 × 距離係数 × 波長位置, -16, 16))` に変更します。波長位置は -1〜1 です。小さい設定では従来の線形方式に近く、大きくしても倍率は正のままです。極端な設定では端の引き伸ばしや縞が出る可能性は残ります。
- 「半径・減衰の適用先」は「収差のみ」「収差＋ラジアル」「収差＋スケール」「すべて」の4種類です。選択した変形に共通の半径・減衰形式・減衰値が作用します。中心を鮮明に保って周辺を変形するには、減衰を正の値にします（冪乗の減衰0は均一です）。
- 初期値は「線形（従来）」「収差のみ（従来）」です。既存プロジェクトの描画設定は変えません。新方式のサンプル数推定には距離係数と指数倍率を含めます。
- 半径の形は従来と同じ画面比の楕円です。真円への変更ではありません。

## ビルド手順

.NET 10 SDK と Windows SDK (fxc.exe) が必要です。

```powershell
$Ymm4DirPath = 'D:\YukkuriMovieMaker_v4_Lite\'
$FxcPath = 'C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\fxc.exe'
$D2DIncludePath = 'C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\um'
dotnet build .\SaChromaticAberration.csproj -c Release "-p:YMM4DirPath=$Ymm4DirPath" "-p:FxcPath=$FxcPath" "-p:D2DIncludePath=$D2DIncludePath"
```

## インストール

`bin\Release\net10.0-windows10.0.19041.0\SaChromaticAberration.dll` を
YMM4 の `user\plugin\SaChromaticAberration\` にコピーして YMM4 を再起動します。

## 構成

- `Shaders/ChromaticAberration.hlsl` — 分光サンプリングと減衰曲線のピクセルシェーダー (ps_4_0)
- `ChromaticAberrationCustomEffect.cs` — D2D カスタムエフェクトと定数バッファ、入力全体の参照範囲指定
- `ChromaticAberrationProcessor.cs` — フレームごとのパラメーター更新
- `ChromaticAberrationEffect.cs` — YMM4 のエフェクト定義 (UI)

## Radial の透明化修正と減衰制御 (2026-09-20)

- 画面外の参照座標を元画像の端の画素中心にクランプします。回転・収差・スケールを強めても、不透明な入力は不透明のままです。
- 出力矩形は入力と同じ大きさです。画面外に端の色を延々と引き伸ばしません。
- 分割描画でも端の画素を読み出せるよう、入力全体を要求します。大きな素材では入力評価コストが増える可能性があります。
- 元から透明な素材は透明度を保ってサンプリングします。アルファを一律に 1 にする処理ではありません。
- 半透明サンプルはアルファを重みに含めて色を平均し、透明サンプルで二重に暗くなる問題も修正しました。
- 端の色を伸ばすため、強い設定では端に引き伸ばし模様が出ます。
- 減衰半径を追加し、中心からの距離スケールを1%〜10000%で制御できるようにしました。
- 減衰形式として冪乗・三乗・四乗・六乗・指数を追加しました。
- 収差、減衰指数、Radial、スケール、中心座標、ステップ数の操作範囲を広げました。

Crate's 本体の実装・同一素材同一設定の出力との一致は未検証です。
