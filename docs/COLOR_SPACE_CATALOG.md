# Color Space Catalog

This branch is the selection/reference branch for the experimental SaChromaticAberration color-space project.

No attempt is made here to implement every entry. The point is to keep all formulas in one branch so a later implementation task can select any subset by name.

## Documents

- `docs/EXPERIMENTAL_COLOR_SPACES.md` — early set, mathematical v2, and deep-math v3.
- `docs/BEAUTIFUL_COLOR_SPACES.md` — beautiful/smooth v4.
- `docs/DESTRUCTIVE_COLOR_SPACES.md` — destructive v5.
- `docs/ADDITIONAL_COLOR_SPACES_V6.md` — ten additional v6 spaces.
